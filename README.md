# ITC327W WIL Project (2026)
## Project Description
An integrated cross-platform software solution featuring a Flutter mobile application and an ASP.NET web app powered by a shared Supabase backend.

## Tech-Stack
* **Mobile Frontend:** Flutter (Dart)
* **Web Portal:** ASP.NET Core (C#)
* **Cloud Backend:** Supabase (PostgreSQL)
